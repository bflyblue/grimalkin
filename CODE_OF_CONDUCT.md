# Code of Conduct

Grimalkin's community should be a constructive place to collaborate. Be
respectful, assume good intent while still discussing evidence, and critique
ideas and code rather than people.

Harassment, discrimination, threats, deliberate intimidation, doxxing, and
repeated disruptive behaviour are not acceptable. This applies in repository
issues, pull requests, reviews, and other project spaces.

Maintainers may edit or remove contributions and may temporarily or permanently
restrict participation when behaviour harms the community. Enforcement should
be proportionate, private where practical, and focused on restoring a safe and
productive environment.

Report conduct concerns to
[Shaun Sharples](mailto:shaun.sharples@gmail.com). Do not include sensitive
personal information in a public issue. Reports will be reviewed as promptly
and confidentially as practical.
