# Grimalkin 0.1.20

Grimalkin 0.1.20 adds a built-in catalogue of popular terminal colour themes
with live selection and automatic persistence through the settings overlay.

## Highlights

- The original Grimalkin palette is now named **Ghostty** and remains the
  default.
- The built-in catalogue adds Dracula, Nord, Gruvbox Dark and Light, Solarized
  Dark and Light, all four Catppuccin flavours, Tokyo Night, and the three
  Rosé Pine variants.
- Moving through **Colour themes** in the settings overlay applies each theme
  immediately. The latest selection is saved automatically, and Escape returns
  to the main settings page without reverting it.
- The catalogue is compiled into Grimalkin, so no separate theme files or
  packages are required on Linux, macOS, or Windows.

## Terminal colour behaviour

- Themes set the terminal's default foreground, background, cursor, and ANSI
  colours 0–15.
- Extended palette colours 16–255 and explicit truecolour output remain
  unchanged.
- Applications can continue to override default and palette colours through
  OSC sequences. Those overrides remain active while the user changes themes.
- Returning to **Ghostty** restores the original Grimalkin defaults and
  Ghostty's standard terminal palette.
- The settings overlay and selection styling remain independent of the active
  terminal theme.

## Packaging and licensing

- Every palette is compiled into the executable from values pinned to an
  official upstream revision.
- Dracula, Nord, Gruvbox, Solarized, Catppuccin, Tokyo Night, and Rosé Pine are
  permissively licensed under the MIT License. Their provenance and notices
  are included in every release package.

## Testing

- Terminal integration tests cover live default and ANSI colour replacement,
  existing-row invalidation, Ghostty restoration, OSC override preservation,
  extended palette stability, and truecolour stability.
- Settings tests cover the Ghostty default, every theme's JSON round trip,
  migration of older settings files, and rejection of unknown theme names.
- OSD tests cover submenu navigation, paging, reset, immediate persistence,
  and keeping the latest theme when leaving the menu.
- The full CPU suite, llvmpipe and hardware Vulkan pixel suites, and Nix flake
  checks pass. Live navigation was also exercised over a rapidly updating
  `htop` session.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility and security notes

Grimalkin remains experimental 0.x software and continues to advertise
`TERM=xterm-256color` and `COLORTERM=truecolor`.

The default OSC 52 policy remains **Write only**. Enabling **Read/write** lets
terminal applications, including applications reached over SSH, query the
local clipboard and should be reserved for trusted sessions.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
