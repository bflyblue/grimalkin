# Grimalkin 0.1.26

Grimalkin 0.1.26 fixes Windows fullscreen windows retaining an explicitly
requested rounded-corner preference.

## Native Windows corners

- Grimalkin no longer forces `DWMWCP_ROUND` on its Win32 window at startup.
- GLFW continues to own the native window styles used for System, Frameless,
  and monitor-attached fullscreen modes.
- Windows DWM now applies its normal corner policy for each window state,
  allowing fullscreen windows to remain square instead of carrying a
  windowed rounded-corner hint.

## Testing

- `nix develop -c make check test build` passes with all 220 Odin tests.
- Linux, Apple Silicon macOS, and Windows x64 pull-request builds pass for the
  merged fix.
- The native Windows compilation path is covered by CI. The visible DWM result
  still requires confirmation on a Windows 11 desktop because the local
  validation host is Linux.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

No settings or public configuration interfaces change in this release.
Grimalkin remains experimental 0.x software and continues to advertise
`TERM=xterm-256color` and `COLORTERM=truecolor`.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
