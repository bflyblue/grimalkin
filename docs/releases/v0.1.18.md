# Grimalkin 0.1.18

Grimalkin 0.1.18 fixes missing CJK and Braille glyphs on macOS. Apple’s
placeholder font no longer ends the fallback cascade before Grimalkin reaches
a system font containing the real character.

## Fixes

- CJK and Braille characters such as `漢`, `⠁`, and `⣿` now render from real
  system fallback fonts on macOS instead of appearing as boxed question marks.
- Font fallback now skips Apple’s `.LastResort` sentinel even when it advertises
  coverage for the requested Unicode character. This check lives at the
  selector boundary so it also protects installations whose Fontconfig policy
  predates this release.
- The bundled macOS Fontconfig policy rejects both `LastResort` family-name
  spellings as a second layer of protection.

## Testing

- The display-compiler regression test now forces CJK and Braille through the
  platform fallback cascade and verifies a real fallback face, non-empty raster
  coverage, and non-empty atlas coverage rather than relying only on a nonzero
  glyph index.
- The Vulkan fallback-growth test includes representative Braille characters
  alongside CJK, Arabic, symbols, and private-use glyphs.
- The rebuilt macOS application was visually checked on the affected device
  with `漢`, `⠁`, and `⣿` rendering without missing-glyph boxes.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility and security notes

Grimalkin remains experimental 0.x software and continues to advertise
`TERM=xterm-256color`.

The default OSC 52 policy remains **Write only**. Enabling **Read/write** lets
terminal applications, including applications reached over SSH, query the
local clipboard and should be reserved for trusted sessions.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
