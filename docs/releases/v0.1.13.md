# Grimalkin 0.1.13

Grimalkin 0.1.13 is a maintenance release focused on renderer ownership,
high-cardinality lookup performance, settings consistency, and native build
reliability across Linux, macOS, and Windows.

## Highlights

- Kitty virtual Unicode-placeholder image and placement lookups now use
  durable indexes, avoiding repeated linear scans while preserving the first
  matching placement and omitted-ID behaviour.
- Loaded fallback fonts are indexed by their complete render-instance key,
  substantially reducing repeated face lookup costs in fallback-heavy text.
- Application, display-compiler, font, and Vulkan responsibilities now have
  clearer source and ownership boundaries. Fullscreen pipelines, mapped-buffer
  growth, swapchain resources, and padding-glow targets share common lifecycle
  helpers without changing the single-quad cell renderer.
- Settings serialization no longer writes the legacy `text_clarity` field.
  Existing version-1 settings that contain it continue to migrate when
  `text_smoothing` is absent, and invalid values retain the established safe
  fallback behaviour.
- Settings-overlay pages use common typed row metadata and keyboard navigation,
  including consistent disabled-row, reset, persistence, and submenu handling.
- Custom `Alt` and middle-mouse window movement, resize, and maximize gestures
  have been removed. Window management now uses standard operating-system
  controls, leaving terminal-area mouse input to selection or applications.
- Native Make-based Linux and macOS builders, the Windows `grimalkin_ci` CMake
  target, shared shader manifests, and common packaging staging are now the
  primary development and CI paths. Nix remains available as an optional local
  development and packaging alternative.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility and security notes

Grimalkin remains experimental 0.x software and continues to advertise
`TERM=xterm-256color`. Kitty direct image placements are not yet rendered;
virtual Unicode-placeholder placements remain supported.

The default OSC 52 policy remains **Write only**. Enabling **Read/write** lets
terminal applications, including applications reached over SSH, query the
local clipboard and should be reserved for trusted sessions.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
