# Grimalkin 0.1.31

Grimalkin 0.1.31 prevents unusual FreeType glyph bitmap formats from crashing
the terminal during Unicode-heavy output.

## Font rendering

- Harmony subpixel rendering now accepts grayscale glyph output by promoting
  its neutral coverage into the fixed RGBA subpixel atlas format.
- Remaining glyph rasterization failures propagate through shaping and fitting
  without triggering an Odin panic or `SIGILL` core dump.
- Grimalkin retries an unrenderable group with the style-matched primary font's
  replacement glyph. If that also fails, only the affected glyph is left blank.
- Rasterization diagnostics include the font path, glyph index, and error code
  and are deduplicated for the lifetime of the renderer.

## Testing

- Linux, Apple Silicon macOS, and Windows x64 CI passed for the font-rendering
  fix.
- The native suite passes all 238 Odin tests, including grayscale promotion,
  replacement rendering, warning deduplication, and replacement failure cases.
- The offscreen GPU suite passes.
- A live 45-second vtebench Unicode stress run with JetBrainsMono Nerd Font,
  subpixel smoothing, and QD-OLED diamond geometry produced no new core dump.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

This patch release does not change the settings format or command-line
interface. The Windows installer is not code-signed, so Microsoft SmartScreen
may display a warning. The macOS image is Developer ID signed and notarized by
Apple.
