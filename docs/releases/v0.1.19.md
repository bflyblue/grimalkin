# Grimalkin 0.1.19

Grimalkin 0.1.19 adds mouse-wheel and high-resolution trackpad navigation
through normal-screen scrollback, while bounding retained terminal history by
memory by default.

## Highlights

- Mouse wheels and two-finger trackpad gestures now scroll normal-screen
  history when the foreground application is not using mouse reporting.
- Mouse-aware applications such as `htop` and nvim continue to receive
  unmodified scrolling. Holding `Shift` temporarily routes the gesture to
  Grimalkin history instead.
- Fractional trackpad deltas accumulate without losing precision, and each
  complete unit moves exactly one terminal row. Horizontal-only gestures are
  ignored.
- Alternate-screen history scrolling remains a no-op because Ghostty exposes
  no scrollback for that screen.

## Bounded scrollback memory

- Normal-screen history now defaults to an approximate 50,000,000-byte limit
  per terminal, with no independent line limit.
- The restart-only `scrollback_limit_bytes` and `scrollback_limit_lines` JSON
  settings accept `-1` for unlimited history and `0` to disable scrollback.
  When both are finite, the first limit reached controls pruning.
- Limits are approximate because Ghostty allocates and prunes complete history
  pages. The line limit counts physical grid rows, including each row produced
  by soft wrapping.
- Idle compression is enabled by default. Grimalkin waits 250 ms after terminal
  activity and then schedules small incremental steps without running Ghostty
  compression concurrently with writes, snapshots, selection, or rendering.
  Compression reduces eligible resident storage without increasing retained
  logical history.

## Testing

- Input tests cover fractional accumulation, direction reversal, multi-row
  deltas, horizontal and zero input, suppression, mouse reporting, `Shift`
  override, and alternate-screen routing.
- Terminal integration tests cover unlimited, disabled, byte-capped, and
  line-capped history, viewport clamping, alternate-screen behavior, and
  compression activity without logical-history changes.
- Scheduler tests cover idle postponement, pending steps, completion,
  unsupported platforms, disabled compression, and minimized-window deadlines.
- Settings tests cover defaults, older-file migration, round trips, finite and
  unlimited values, disabled history and compression, invalid values, and the
  platform `size_t` boundary.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility and security notes

Grimalkin remains experimental 0.x software and continues to advertise
`TERM=xterm-256color`.

The default OSC 52 policy remains **Write only**. Enabling **Read/write** lets
terminal applications, including applications reached over SSH, query the
local clipboard and should be reserved for trusted sessions.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
