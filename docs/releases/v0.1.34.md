# Grimalkin 0.1.34

Grimalkin 0.1.34 completes mouse selection gestures and stops a highlighted
region from lying about what it contains. A selection now follows its text when
a full-screen application such as Vim scrolls, and clears itself before it could
point at different content.

## Terminal selection

- Click counting is per screen: double-click selects the word under the cursor,
  and a third or later click selects the logical line. Click sequences no longer
  leak between the alternate screen of a full-screen program and the normal
  screen.
- Dragging extends a word or line selection using terminal semantics rather than
  raw cell ranges, so word separators, a change of drag direction, and
  soft-wrapped lines behave the way the terminal defines them.
- A selection tracks its own text. When output genuinely scrolls the terminal,
  the highlight and the copied content move with that text instead of staying
  pinned to screen rows.
- A selection clears when the selected text is overwritten in place, and clears
  when keyboard or mouse input is forwarded to the application. Repaints that do
  not change the selected text, and updates elsewhere in the terminal, keep the
  selection alive.
- The practical result: you cannot copy text that a repaint has already replaced,
  and a stale highlight cannot survive while you type into the program.

## Testing

- The native suite passes all 252 Odin tests, covering click counting,
  word and line drag bounds, direction changes, soft-wrapped lines, scroll
  tracking, repaint reconciliation, and clearing on forwarded input.
- An isolated Xvfb and llvmpipe smoke test drove Vim with mouse reporting
  enabled: a Shift-drag produced a visible host selection, and a forwarded wheel
  event scrolled Vim from line 1 to line 4 and removed the highlight.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

This patch release does not change the settings format or command-line
interface. The Windows installer is not code-signed, so Microsoft SmartScreen
may display a warning. The macOS image is Developer ID signed and notarized by
Apple.
