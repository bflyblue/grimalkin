# Grimalkin 0.1.12

Grimalkin 0.1.12 is the project's first public release: a native,
cross-platform terminal emulator built with Odin, Vulkan, and
`libghostty-vt`.

## Highlights

- Native PTY sessions on Linux and macOS and ConPTY sessions on Windows.
- Unicode shaping, programming ligatures, wide characters, colour emoji, and
  system-font fallback through HarfBuzz, FreeType, and Fontconfig.
- A shared single-quad Vulkan renderer, including MoltenVK on Apple Silicon.
- Scrollback, keyboard paging, linear and rectangular selection, bracketed
  paste, system clipboard integration, and configurable OSC 52 access.
- Live controls for fonts, grayscale or Harmony subpixel rendering, cursor
  animation, padding effects, key bindings, clipboard behaviour, and window
  style.
- Kitty graphics displayed through virtual Unicode placeholders and optional
  bundled Nerd Font symbols.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility and security notes

Grimalkin remains experimental 0.x software. It advertises
`TERM=xterm-256color`; Kitty direct image placements are not yet rendered,
although virtual Unicode-placeholder placements are supported.

The default OSC 52 policy is **Write only**. Enabling **Read/write** allows
terminal applications, including applications reached over SSH, to query the
local clipboard and should be reserved for trusted sessions.

The Windows installer is not code-signed in this release, so Microsoft
SmartScreen may display a warning. The macOS image is Developer ID signed and
notarized by Apple.
