# Grimalkin 0.1.22

Grimalkin 0.1.22 adds direct mouse interaction to the terminal scroll
indicator while preserving the existing scrollback and input-routing model.

## Draggable scroll indicator

- The scroll thumb can now be dragged to move proportionally through terminal
  history, including while a terminal application has mouse reporting enabled.
- The slim 3-pixel indicator retains its existing appearance while gaining a
  24-logical-pixel minimum thumb length and a clipped 12-logical-pixel-wide
  grab target.
- At live output, moving the pointer over the hidden thumb location reveals
  the indicator. It remains visible while hovered or dragged, then follows the
  existing hold and fade timing after the pointer leaves.
- Dragging preserves the pointer's position within the thumb, clamps cleanly at
  both ends of the track, and continues to use Ghostty's viewport state and the
  same row-scrolling refresh path as wheel and keyboard scrolling.
- Scrollbar interaction takes priority over URL activation, selection, and
  terminal mouse reports. Modal OSD and paste-confirmation screens continue to
  block scrollbar grabs, and clicks outside the thumb retain their previous
  behaviour.

## Testing

- Geometry tests cover minimum thumb sizing, display scaling, the clipped hit
  target, proportional travel, anchored dragging, endpoint clamping, and safe
  signed row deltas.
- Input tests cover hover visibility, leave/fade timing, detached resting
  opacity, drag visibility at live output, invalid-geometry release handling,
  and routing precedence.
- Vulkan pixel tests cover the minimum-sized thumb together with the existing
  scissor, rounding, and opacity behaviour.
- The complete 207-test Odin suite, application build, deterministic llvmpipe
  Vulkan suite, and Intel hardware Vulkan validation pass for this change.
- Linux, Apple Silicon macOS, and Windows pull-request builds pass.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

No settings or public configuration interfaces change in this release.
Grimalkin remains experimental 0.x software and continues to advertise
`TERM=xterm-256color` and `COLORTERM=truecolor`.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
