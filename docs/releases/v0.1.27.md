# Grimalkin 0.1.27

Grimalkin 0.1.27 restores rounded corners for windowed Frameless mode on
Windows without reintroducing rounded fullscreen corners.

## State-aware Windows corners

- Windowed Frameless mode opts into Windows 11 DWM rounded corners.
- System windows and fullscreen restore `DWMWCP_DEFAULT`, leaving their corner
  policy to Windows.
- Entering fullscreen resets the Frameless preference before GLFW attaches the
  window to a monitor. Leaving fullscreen reapplies the configured window
  style and its corresponding preference.
- Startup, F12 style changes, and fullscreen restoration share the same state
  mapping, with no new setting or persisted state.

## Testing

- The state mapping is covered for System and Frameless in both windowed and
  fullscreen modes.
- `nix develop -c make check test build` passes with all 221 Odin tests.
- Linux, Apple Silicon macOS, and Windows x64 pull-request builds pass for the
  merged fix.
- The native Windows compilation path is covered by CI. Visual confirmation of
  restored Frameless rounding still requires a Windows 11 desktop.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

No settings or public configuration interfaces change in this release.
Grimalkin remains experimental 0.x software and continues to advertise
`TERM=xterm-256color` and `COLORTERM=truecolor`.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
