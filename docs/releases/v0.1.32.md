# Grimalkin 0.1.32

Grimalkin 0.1.32 makes Unicode-heavy terminal output dramatically faster,
allows the glyph cache to grow without disruptive renderer resets, and fixes
input remaining suppressed after an unsafe paste is approved.

## Unicode and font fallback

- Emoji colour-font selection now follows the pinned Unicode 17
  `Emoji_Presentation` property instead of treating every wide terminal cell as
  an emoji candidate. CJK, Hangul, and other wide text go directly through the
  normal font fallback path.
- Fontconfig's ordered fallback catalogs are built once per renderer rather
  than sorted again for every previously unseen grapheme.
- Fallback results use a bounded cache with eviction; exhausting that cache no
  longer rebuilds all text resources.
- Optional `GRIMALKIN_PERF_STATS=1` diagnostics report fallback, shaping,
  rasterization, and atlas counters when Grimalkin exits.

## Glyph atlas management

- Text glyphs can roll over into additional atlas generations while existing
  visual identifiers remain stable.
- The shared atlas budget is derived from device-local GPU memory and bounded
  between 64 MiB and 256 MiB.
- Cold generations are retired once atlas use crosses the soft limit. If the
  hard limit is reached, Grimalkin warns once and leaves only the uncached glyph
  blank instead of tearing down and rebuilding the renderer.

## Paste protection

- Releasing Shift+Insert after it opens the unsafe-paste confirmation now
  completes the shortcut lifecycle. Previously the release was swallowed by
  the modal, leaving character input suppressed after approval.
- Enter and Escape releases used to accept or cancel the prompt are kept away
  from applications that enable enhanced key-release reporting, including
  Neovim.

## Performance and testing

- On the affected Omarchy machine, the 1.06 MiB vtebench Unicode workload fell
  from 62,539 ms to 147-231 ms.
- Linux, Apple Silicon macOS, and Windows x64 CI passed.
- The native suite passes all 241 Odin tests, including Unicode presentation,
  fallback-cache eviction, atlas rollover and retirement, and paste key
  lifecycle coverage.
- The fixed build was tested interactively on an NVIDIA GeForce RTX 4090.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

This patch release does not change the settings format or command-line
interface. The Windows installer is not code-signed, so Microsoft SmartScreen
may display a warning. The macOS image is Developer ID signed and notarized by
Apple.
