# Grimalkin 0.1.29

Grimalkin 0.1.29 improves startup on display-less or misconfigured systems,
adds explicit multi-GPU selection, and fixes duplicate character input under
X11 and XWayland.

This supersedes the unpublished `v0.1.28` tag, whose Debian package validation
exposed a surface-compositing compatibility issue before any release was
published.

## Multi-GPU selection

- Grimalkin now considers every Vulkan adapter compatible with the current
  GLFW surface and renderer requirements instead of committing to the first
  partially suitable device.
- Logical-device and swapchain failures fall through to the next suitable
  adapter with a clear diagnostic.
- Swapchains prefer opaque compositing but negotiate premultiplied,
  postmultiplied, or inherited alpha when that is what the window surface
  supports.
- A new **Graphics** settings page shows the active adapter. Systems with both
  suitable integrated and discrete GPUs can choose **Power saving**, **High
  performance**, or **Automatic**.
- GPU preference changes apply live while preserving the terminal session and
  CPU-side display state. The preference is saved as `gpu_preference`; if its
  device class is unavailable later, Grimalkin retains it and marks the active
  device as a fallback.

## Startup and command-line handling

- `grimalkin --help` and `grimalkin --version` now complete before GLFW or
  Vulkan initialization, so they work without a display server.
- Unknown options produce a conventional diagnostic and exit status 2 instead
  of being silently ignored.
- GLFW, Vulkan loader, Vulkan instance, window, surface, logical-device, and
  swapchain initialization failures now report actionable errors and exit
  cleanly instead of raising an Odin system exception.

## X11 input

- Printable input is no longer flushed at GLFW event-poll boundaries. This
  avoids sending one key twice when X11 or XWayland delivers the key callback
  and character callback in separate polls.
- The character callback owns ordinary, shifted, Alt, and AltGr text, while
  known non-character Ctrl and Super combinations continue through the key
  callback immediately.

## Testing

- `make check`, `make test`, and `make build` pass with all 235 Odin tests.
- Linux, Apple Silicon macOS, and Windows x64 CI passed for all three merged
  changes.
- `--help` and `--version` were verified with both `DISPLAY` and
  `WAYLAND_DISPLAY` unset; unknown-option diagnostics were also checked.
- Interactive Linux testing selected an NVIDIA GeForce RTX 4090 successfully.
  The isolated offscreen Vulkan test environment had no compatible driver and
  returned `ERROR_INCOMPATIBLE_DRIVER`; the new clean failure path was verified.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

Existing settings remain compatible. Grimalkin adds the optional
`gpu_preference` setting, which defaults to `automatic` when absent. Grimalkin
remains experimental 0.x software and continues to advertise
`TERM=xterm-256color` and `COLORTERM=truecolor`.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
