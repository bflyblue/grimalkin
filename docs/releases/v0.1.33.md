# Grimalkin 0.1.33

Grimalkin 0.1.33 prevents FIFO presentation from blocking terminal input and
avoids drawing unchanged frames speculatively after ordinary key presses.

## Input and presentation latency

- Interactive rendering now checks frame fences and acquires swapchain images
  without blocking the event-loop thread. When the compositor has no image
  available, Grimalkin keeps the redraw pending, continues processing window
  events and PTY output, and retries within one millisecond.
- Benchmarks and headless rendering retain their blocking behavior, where
  deterministic serialized frames are intentional.
- Ordinary terminal input no longer submits an unchanged frame before the
  application responds through the PTY. Immediate redraws remain for local
  visual changes such as clearing a selection or returning from scrollback.

## Performance and testing

- On the affected 4K Wayland system at 60 Hz with FIFO presentation and a
  pulsing cursor, mean key-to-PTY latency fell from approximately 33 ms to
  0.57 ms. Mean key-to-present-submission latency fell from approximately
  50 ms to 10.32 ms, with a 17.39 ms 95th percentile.
- The 1.06 MiB vtebench Unicode workload completed in 138.58 ms instead of
  62,539 ms in the earlier blocked run. Medium-cell and synchronized
  medium-cell workloads were approximately 3.7 times faster, while scrolling
  region performance remained comparable.
- Linux, Apple Silicon macOS, and Windows x64 CI passed.
- The native suite passes all 242 Odin tests, and the combined build was tested
  interactively on an NVIDIA GeForce RTX 4090 at both 60 Hz and 240 Hz.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

This patch release does not change the settings format or command-line
interface. The Windows installer is not code-signed, so Microsoft SmartScreen
may display a warning. The macOS image is Developer ID signed and notarized by
Apple.
