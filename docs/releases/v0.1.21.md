# Grimalkin 0.1.21

Grimalkin 0.1.21 is a stability and security patch for colour themes, terminal
I/O, clipboard handling, input state, font discovery, and pull-request builds.

## Colour themes and settings

- Window padding, padding glow, and pixels outside the centred cell grid now
  use the active terminal theme background instead of the Ghostty default.
- The colour-theme browser resynchronizes its highlighted row after a global
  settings reset, and accented theme names align correctly in the OSD.
- A failed live theme change now restores the last working theme and reports
  the failure instead of terminating the terminal.
- Repeated theme-navigation events are coalesced into one full display
  recompile per event batch, while each selected theme still applies live.
- Multiline paste confirmation is enabled by default for new and migrated
  settings. An explicitly saved disabled preference remains disabled.
- Shared list navigation, settings wire values, theme initialization, and reset
  bookkeeping have been consolidated without changing saved theme names.

## Terminal and input reliability

- PTY writes larger than one megabyte now grow the outgoing queue safely while
  preserving order, covering large pastes and OSC 52 responses on Unix and
  Windows.
- Terminal parsing is capped at 256 KiB per application-loop iteration so
  sustained output cannot starve keyboard, mouse, or window events.
- Unix PTY pixel extents clamp without integer wrap, shutdown escalates after a
  bounded grace period for SIGHUP-resistant children, and a Windows pipe error
  path no longer leaks its first handle.
- Mouse-button state is updated before OSD and paste-confirmation routing, so
  terminal mouse reports cannot inherit a stale pressed-button bit.
- OSC 52 clipboard writes now use libghostty-vt's normalized callback. Denied
  clipboard reads receive an empty response instead of hanging or revealing
  the active clipboard policy through silence.

## Fonts, packaging, and CI security

- Saved and type-ahead font matching handles non-ASCII family names without
  corrupting their UTF-8 bytes.
- Bundled Nerd Font assets are resolved relative to the executable rather than
  the process working directory, including native staged development builds.
- Untrusted pull-request dependency caches are isolated per PR and may fall
  back only to rotated caches seeded from trusted `main` builds.

## Testing

- Regression coverage includes themed padding pixels, Unicode OSD alignment,
  theme rollback and refresh coalescing, UTF-8 font matching, mouse state, PTY
  geometry and shutdown, large writes, bounded draining, and OSC 52 policy.
- The complete native/Odin suite, deterministic llvmpipe Vulkan pixel suite,
  application build, Nix flake checks, and Nix package build pass for the
  release commit.
- Linux, Apple Silicon macOS, and Windows pull-request builds pass for every
  merged fix.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility and security notes

Grimalkin remains experimental 0.x software and continues to advertise
`TERM=xterm-256color` and `COLORTERM=truecolor`.

The default OSC 52 policy remains **Write only**. Enabling **Read/write** lets
terminal applications, including applications reached over SSH, query the
local clipboard and should be reserved for trusted sessions.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
