# Grimalkin 0.1.24

Grimalkin 0.1.24 adds configurable fullscreen shortcuts and a window-style
shortcut, with monitor-aware fullscreen placement and reliable restoration of
the previous window state.

## Fullscreen and window-style shortcuts

- Fullscreen now defaults to both `Alt+Enter` and `F11`. The **Key bindings**
  settings page can select either shortcut individually or keep both enabled.
- An optional `F12` shortcut switches between System and Frameless window
  styles while windowed. It is enabled by default and persists the selected
  style through the existing automatic settings save.
- Application shortcuts remain active while the settings overlay is open.
  Paste confirmation retains higher modal priority.
- Shortcut matching ignores Caps Lock and Num Lock while rejecting additional
  semantic modifiers. `Alt+Enter` accepts only the regular Enter key, and
  `F11` and `F12` remain unmodified bindings.
- Shortcut press, repeat, and release events are consumed consistently, while
  only the initial press changes application state.

Fullscreen attaches the GLFW window to the current video mode of the monitor
containing the largest portion of the window, falling back to the primary
monitor. Leaving fullscreen restores the saved client position and size,
reapplies the configured window style, and restores maximization when needed.
Window-style changes selected from the settings overlay are deferred while
fullscreen, and `F12` remains ordinary terminal or modal input until the
window returns to windowed mode.

## Testing

- Settings tests cover defaults, missing-field migration, every fullscreen
  wire value, the enabled and disabled `F12` setting, and invalid-value repair.
- OSD tests cover the expanded five-row Key bindings page, labels, adjustment,
  individual and grouped resets, global reset, navigation, and panel sizing.
- Input and geometry tests cover exact modifiers, lock modifiers, keypad
  Enter, disabled alternatives, event suppression, settings-overlay routing,
  terminal forwarding, style persistence, monitor selection, fallback, and
  normal and maximized restoration plans.
- The complete 220-test Odin suite and application build pass, along with
  Linux, Apple Silicon macOS, and Windows pull-request builds.

## Downloads

The release includes:

- a signed, notarized, and stapled Apple Silicon DMG for macOS 14 or newer;
- an x86-64 AppImage plus Debian, Ubuntu, and Arch Linux packages; and
- an x64 installer for Windows 11 24H2 or newer.

Each downloadable artifact is accompanied by a SHA-256 checksum. Linux and
Windows packages require a Vulkan 1.2-capable GPU and current graphics driver;
the Windows package also requires the Visual C++ Redistributable.

## Compatibility notes

Existing settings files receive the new shortcut defaults automatically.
Unknown fullscreen shortcut values are repaired to the default of both
`Alt+Enter` and `F11`. Grimalkin remains experimental 0.x software and
continues to advertise `TERM=xterm-256color` and `COLORTERM=truecolor`.

The Windows installer is not code-signed, so Microsoft SmartScreen may display
a warning. The macOS image is Developer ID signed and notarized by Apple.
